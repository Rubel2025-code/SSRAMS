{% comment %} Renders every visible field of `form` with Bootstrap 5 markup plus errors, so that no template has to duplicate the field-loop markup. Included by eight forms across two apps: accounts/login, accounts/register_student, accounts/register_provider, accounts/student_profile_form, accounts/provider_profile_form, scholarships/provider_form, scholarships/provider_criteria and scholarships/provider_criterion_edit. It lives under accounts/ for historical reasons only -- it is app-neutral, and the path is referenced by all eight includes, so it stays put. PROMPT 9 (UI/UX) NOTES — this partial had a dangling-reference bug: Django 5.2 already renders each widget with aria-invalid="true" aria-describedby="_helptext _error" but this template emitted the help text and the errors with *no id at all*, so every one of those references pointed at nothing. A screen reader therefore announced neither the help text nor the validation error. The ids below are not decorative -- they must stay exactly `{{ field.auto_id }}_helptext` and `{{ field.auto_id }}_error`, because Django generates the aria-describedby value from that pattern. Because Django supplies aria-invalid itself, the invalid styling is driven from CSS ([aria-invalid="true"] in base.css) rather than by injecting Bootstrap's .is-invalid class here -- that would need widget attrs set in forms.py, and the visual result is identical.
